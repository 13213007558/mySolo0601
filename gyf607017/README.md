# 婴幼儿睡眠观察提醒墙 · 儿保随访版

全栈应用：录入材料 → 提交复核 → 退回补充 → 复核通过 → 关闭归档，全程在一条时间线上完成。
所有换班后的操作都会留下完整审计（旧值、处理人、复核时间），方便社区儿保护士和早班老师追溯。

---

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 18 + Vite + React Router |
| 后端 | Node.js + Express |
| 数据库 | SQLite（better-sqlite3，零配置） |
| 文件上传 | Multer |
| 导出 | json2csv（CSV 格式，带 BOM，Excel 直接打开） |

## 🔄 完整流程演示

在页面右上角切换身份进行：

| 步骤 | 操作人 | 做什么 |
|---|---|---|
| 1. 录入 | 护士小陈 / 小李 / 小王 | 观察记录 → 新增记录 → 填写表单 → 保存并提交复核 |
| 2. 复核 | 主管王老师 | 点击某条「待复核」记录 → 查看时间线 → 复核通过 或 退回补充 |
| 3. 补充 | 护士（原录入人） | 被退回的记录可以「修改记录」后再次「提交复核」 |
| 4. 归档 | 早班老师 | 已通过的记录 → 关闭归档 |

每个步骤都会在右侧「处理时间线」和下方「审计留痕」表中留下记录。

## ⚠️ 触发异常（部分成功）场景

### 场景：护士录入时忘记拍照片，仍然要把数据报上去

1. 点击 **+ 新增记录**
2. 勾选「我将上传现场观察照片」
3. **不** 选择照片文件
4. **不** 勾选「允许部分成功」直接保存 → 会报错："照片缺失"
5. 现在勾选 **⚠️ 允许部分成功（照片缺失时仍保存，计入异常审计，主管可复查）**
6. 再次点击「保存并提交复核」

结果：
- ✅ 记录成功保存，状态为「待复核」
- 🏷️ 列表中会显示 **⚠️照片缺失** 红色标签
- 🔍 「导出/审计」页面的 **异常 / 部分成功记录审计** 表中会出现这条记录
- 📊 数据汇总时这条记录仍计入总数（因为业务上不能漏报），但通过审计标记让主管知道它异常

## 🔍 护士改记录后刷新验证历史留痕

这是核心需求，请按以下步骤操作确认：

1. 打开任意一条草稿/已退回状态的记录（例如样例中 **赵阳阳 昨日记录**）
2. 注意右侧「处理时间线」和下方「审计留痕」中已有的历史
3. 点击「✏️ 修改记录」，随便改一个字段（比如：睡眠时长从 1.5 改成 2.0，或睡眠质量从「较差」改成「一般」）
4. 点击「保存修改」
5. **按浏览器的刷新按钮（F5 或 Cmd+R）刷新整个页面**
6. 观察：
   - ✅ 右侧时间线：新增了一条 **修改** 事件，记录了修改的字段
   - ✅ 下方审计留痕表：新增了一行，类型为「修改」，**旧值** 列显示修改前的值，**新值** 列显示修改后的值
   - ✅ 操作人 列显示了当前登录的用户名
   - ✅ 操作时间 列记录了精确时间

即便换班，下一班护士点开这条记录，也能看到上一位护士的所有修改痕迹。

## 📥 查看导出

### 1. 页面顶部 → 切换到「导出 / 审计」标签

你会看到：
- **数据汇总**：总数、各状态数量、照片缺失数、异常数，一句中文总结
- **异常 / 部分成功记录审计**：只显示异常记录，供主管复查（标红）
- **完整审计日志**：所有操作的完整流水

### 2. 导出 CSV 文件

点击按钮：
- **📥 导出观察记录 CSV** → `sleep_records.csv`（所有观察记录，Excel 直接打开）
- **🔍 导出审计日志 CSV** → `audit_log.csv`（完整审计流水，含旧值/新值/操作人/时间）

CSV 文件带 UTF-8 BOM，双击用 Excel/WPS 打开不会乱码。

## 📑 数据表设计

| 表 | 用途 |
|---|---|
| children | 儿童档案 |
| records | 睡眠观察记录（含 `photo_missing` 标记照片缺失、`status` 状态流转） |
| timeline_events | 时间线事件（给护士/老师看的友好展示） |
| audits | 审计日志（`old_value`/`new_value` JSON 存所有变更，主管复查用） |

每次状态流转或字段修改都会**同时**写入 `timeline_events` 和 `audits` 两张表。

## 💡 常见问题

**Q: 数据库在哪？我想清空重来？**
A: 删除 `data/tracker.db`，然后重新执行 `npm run seed`。

**Q: 上传的照片在哪？**
A: `uploads/` 目录下，URL 通过 `/uploads/xxx` 访问。

**Q: 早班老师只看最后表格？**
A: 是的，「观察记录」列表就是最终表格视图；「导出/审计」里的 CSV 也可以直接给早班老师。

**Q: 护士换班后看不到上一轮处理？**
A: 点任意记录进入详情，右侧「处理时间线」展示全过程，下方「审计留痕」表精确到每个字段的旧值、谁改的、什么时候改的。
