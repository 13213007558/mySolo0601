# 能源快充账单对账系统

专为资产台账专员设计的快充账单对账工作台，解决支付流水备注与试运行报告不同步、重复导入难追溯、异常数据难识别的痛点。

## 核心特性

- 🎯 **内置三类样例数据**：正常、异常、空数据一键切换，无需导入外部文件即可完整测试
- 🔍 **多维度筛选**：按车牌、支付流水备注、退款标记、枪号、状态灵活筛选
- 📊 **智能图表联动**：枪号使用率、金额趋势、异常占比实时可视化
- 📥 **重复导入检测**：自动识别重复记录和材料缺失记录，支持退回补材料
- 👩‍💼 **客服补录通道**：客服阿宁手工补录支付流水备注，差异对比高亮显示
- 🔄 **全链路联动**：支付流水、枪号占用、退款重算、司机排队实时联动
- 📤 **智能导出**：Excel导出自动标注筛选未采用原因

## 📖 使用指南

### 一、查看内置样例数据

系统内置三套完整样例数据，在左侧「数据操作」面板中一键切换：

| 样例类型 | 说明 | 场景 |
|---------|------|------|
| 🟢 正常样例 | 所有账单数据正常，无异常 | 验证正常对账流程 |
| 🔴 异常样例 | 包含日期不一致、金额异常、备注缺失、枪号异常、试运行报告缺失等多种异常 | 测试异常识别和处理 |
| ⚪ 空数据 | 无交易记录，仅显示枪号基础信息 | 测试空状态展示 |

**操作步骤**：
1. 找到左侧「数据操作」面板 → 「内置样例数据」区域
2. 点击对应按钮即可切换，数据和图表会自动刷新
3. 切换样例会自动清空本地存储的操作历史

### 二、触发重复导入多出有效记录

系统内置模拟导入功能，可触发完整的重复检测和退回补材料流程。

**操作步骤**：

1. 确保当前已加载「正常样例」或「异常样例」数据
2. 点击左侧「数据操作」面板中的 **「模拟导入（触发重复检测）」** 按钮
3. 系统会自动生成模拟导入数据，包含三类记录：
   - ✅ **可正常导入记录**：材料齐全的新记录
   - ⚠️ **需退回补材料记录**：试运行报告缺失、支付流水备注日期缺失、或两者日期不一致
   - ❌ **重复记录**：与现有记录（车牌+枪号+交易时间）完全匹配，已自动跳过
4. 弹出「需要退回补材料」窗口，显示详细的检测结果：
   - 黄色高亮显示需要退回的记录及原因
   - 灰色显示已自动跳过的重复记录
   - 绿色显示可正常导入的记录
5. 点击 **「确认退回，要求补材料」** 完成流程：
   - 需退回的记录将标记为「退回」状态，记录到导入历史
   - 可正常导入的记录将自动添加到账单列表
   - 导入历史面板显示本次操作详情

**退回触发条件**（满足任一即可触发）：
- 试运行报告日期缺失
- 支付流水备注日期缺失
- 试运行报告与支付流水备注日期不一致

### 三、筛选后图表未同步的导出说明

当筛选条件变更但未点击「应用筛选」同步到图表时，系统会自动提示，并在导出时标注原因。

**操作步骤**：

1. 在左侧「筛选条件」面板中设置任意筛选条件（如选择车牌号、输入备注关键词等）
2. 注意观察：
   - 数据表格会立即按照筛选条件更新
   - 图表区域右上角会显示 **「图表未同步筛选」** 橙色标签
   - 顶部会出现「筛选条件未应用于图表」的提示条
3. 此时点击 **「导出 Excel（含未采用原因）」** 按钮
4. 打开导出的 Excel 文件，查看两个工作表：
   - **「快充账单明细」**：最后一列「未采用筛选原因」会列出具体原因
   - **「筛选条件说明」**：详细记录导出时的筛选条件和未采用说明

**未采用原因说明示例**：
```
车牌号筛选条件未应用于图表数据
支付流水备注筛选条件未应用于图表数据
枪号筛选条件未应用于图表数据
筛选条件已变更但图表尚未刷新，请点击"应用筛选"按钮更新图表
```

### 四、客服阿宁手工补录支付流水备注

系统内置客服补录通道，支持手工补充缺失的支付流水备注。

**操作步骤**：

1. 在数据表格中找到需要补录的记录（如备注为空的异常记录）
2. 点击该行最右侧的 **✏️ 编辑图标**
3. 右侧联动看板区域会切换为「客服补录」面板，显示：
   - 客服-阿宁专属标识
   - 当前订单的基本信息（车牌号、枪号、金额、交易时间）
4. 在「支付流水备注」文本框中输入备注内容
5. （可选）在「补录原因」中输入补录原因，如：
   - 「试运行报告与支付流水备注日期不一致」
   - 「客服来电补充支付备注」
   - 「对账异常人工复核」
6. 点击 **「保存补录记录」** 按钮
7. 系统自动记录补录历史，可点击「显示差异对比」查看：
   - 补录前内容（删除线标记）
   - 补录后内容（新增部分绿色高亮，删除部分红色高亮）

**验证补录前后差异**：
- 补录后表格中「补录」列会显示「已补录」绿色标签
- 再次导出 Excel 时，「补录前备注」「补录后备注」「补录操作人」「补录时间」列会自动填充
- 可通过再次导出并读回 Excel 验证补录数据的完整性

### 五、值班员操作流程

值班员标准操作流程（按系统顶部提示）：

1. **第一步：按车牌过滤**
   - 在左侧「筛选条件」→「车牌号」中点击目标车牌
   - 右侧联动看板会自动联动：
     - 枪号热力图仅显示该车使用过的枪号
     - 司机排队列表仅显示该车牌的排队记录
     - 支付流水状态、退款记录同步过滤

2. **第二步：对比导出异常金额**
   - 确认筛选条件后，点击「应用筛选」同步图表
   - 点击「导出 Excel（含未采用原因）」
   - 在导出文件中对比异常金额列，核对异常账单

## 🔗 前端联动机制

系统实现四大模块实时联动：

```
车牌筛选 → 支付流水过滤 → 枪号热力图高亮
                ↓
         退款记录关联 → 重算轨迹展示
                ↓
         司机排队过滤 → 等待时间统计
```

**联动效果**：
- 选择特定车牌后，枪号热力图中未使用的枪号会变暗
- 有退款标记的记录会在金额旁显示退款图标
- 司机排队列表自动过滤，只显示筛选车牌的排队记录
- 退款重算时间线只展示相关订单的退款详情

## 💡 常见问题

**Q: 切换样例数据后，我之前的补录记录去哪了？**
A: 切换样例会自动清空 localStorage 中的操作历史，这是正常设计，确保不同样例数据隔离。

**Q: 为什么筛选后图表没有变化？**
A: 为避免频繁重绘影响性能，筛选条件需要点击「应用筛选」按钮才会同步到图表。未应用时导出会自动标注原因。

**Q: 如何验证导出的补录数据？**
A: 补录后再次导出 Excel，打开文件查看「补录前备注」「补录后备注」「补录操作人」「补录时间」列，可与系统内显示的补录历史对比验证。

**Q: 重复导入的判断规则是什么？**
A: 基于「车牌号 + 枪号 + 交易时间」三者组合判断，完全相同即视为重复记录，自动跳过。
