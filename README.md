# 施工日志照片归档台

一个纯前端的施工照片管理系统，使用 SvelteKit + 浏览器本地存储构建，帮助资料员高效归档施工日志、手机照片和备注，支持按日期、楼层、工序快速检索并生成交接摘要。

## ✨ 核心功能

### 📸 照片归档
- **拖拽上传**：支持拖拽或点击上传多张照片
- **智能元数据**：每张照片可标注日期、楼层、工序、备注
- **重复检测**：基于文件哈希自动检测重复照片
- **缩略图优化**：自动生成缩略图，提升浏览性能
- **本地存储**：所有数据保存在浏览器 localStorage 中

### 🔍 多维度检索
- **日期时间轴**：日历视图，快速定位有照片的日期
- **楼层筛选**：按楼层快速筛选
- **工序筛选**：按施工工序筛选（砌筑、钢筋、模板、混凝土、防水、抹灰、其他）
- **关键词搜索**：按备注内容全文搜索
- **状态筛选**：按完成/待确认状态筛选

### 📋 批量操作
- **批量选择**：支持全选、单选、批量操作
- **批量编辑**：批量修改楼层、工序、备注
- **批量标记**：一键标记为完成/待确认
- **批量删除**：支持删除选中照片

### ⚠️ 待补证据
- 自动识别有施工日志但无照片证据的条目
- 可折叠面板，不干扰主视图
- 一键跳转到对应日期

### 📝 Markdown 交接摘要
- 按日期、楼层、工序自动分组
- 支持自定义筛选条件
- 一键复制 Markdown 文本
- 下载 `.md` 文件到本地
- 实时预览渲染效果

### 🛡️ 异常处理
- **中文大写楼层自动转换**：「十八层」→「18层」
- **特殊符号转义**：防止 XSS，确保页面稳定
- **缺日期验证**：上传时必填日期
- **存储容量提示**：localStorage 不足时友好提示
- **重复上传可读提示**：显示重复照片的日期和工序

## 🚀 快速开始

### 启动开发服务器

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:5173 即可使用

### 首次使用

1. 打开页面后，点击「加载样例数据」按钮
2. 系统会自动加载 6 张样例照片和 3 条施工日志
3. 样例数据包含以下测试场景：
   - 中文大写楼层（「十八层」自动转为「18层」）
   - 特殊符号备注测试
   - 重复上传测试
   - 待补证据测试
4. 返回归档台主页体验完整功能

### 交接摘要导出路径

1. 点击顶部导航栏「交接摘要」
2. 设置筛选条件（日期范围、楼层、工序、状态）
3. 点击右上角「下载 .md 文件」
4. 文件保存位置：浏览器默认下载目录
5. 文件名格式：`交接摘要_YYYYMMDD_HHMMSS.md`

### 异常场景测试

1. **空态**：首次打开或清空数据后显示欢迎页
2. **中文大写楼层**：上传时输入「十八层」自动转为「18层」
3. **特殊符号**：备注包含 `<script>alert('xss')</script>` 自动转义
4. **重复上传**：上传同一张照片会提示「该照片已于 XXXX年XX月XX日 · XX工序 已存在」
5. **缺日期**：上传时未选日期会提示错误提示
6. **筛选无结果**：调整筛选条件后显示空态提示

## 🎨 设计特点

- **工业实用风**：暖橙色（#F59E0B）主调，硬朗边框风格
- **响应式设计**：完美适配桌面端和移动端
- **流畅动画**：页面切换、元素交互动画
- **空态设计**：四种空态场景（首次使用、筛选无结果、全部完成、上传区域）
- **无障碍**：支持键盘导航、语义化 HTML

## ⚠️ 注意事项

1. **数据备份**：所有数据仅存储在浏览器本地，清理浏览器数据会导致数据丢失，请定期导出备份
2. **存储限制**：localStorage 容量通常为 5MB 左右，建议单张照片不超过 2MB
3. **浏览器兼容**：建议使用 Chrome、Edge、Safari 最新版本
4. **跨设备同步**：本项目不支持跨设备同步，如需迁移请使用导出/导入功能
