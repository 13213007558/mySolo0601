## 1. 产品概述

婴幼儿辅食禁忌对账台（门店售后版）是面向母婴门店店长的售后对账工具，用于核对婴幼儿辅食食材禁忌与实际出餐是否一致，帮助店长快速发现问题、处理售后、导出核对结果。
- 解决场景：早会前店长手持三日食材表和餐盘照片，需要确认厨房是否按最新标准备料，避免因禁忌食材引发家长投诉
- 目标用户：母婴门店店长、售后客服
- 产品价值：标准化禁忌对账流程，完整保留操作痕迹，导出结果可直接转交给同事处理

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 门店店长 | 内置账号（单机版无登录） | 查看对账列表、详情、手工补录、人工改判、筛选导出 |
| 客服人员 | 接收导出文件 | 仅阅读导出摘要，无系统操作权限 |

### 2.2 功能模块

1. **对账列表页**：筛选条件（手机号）、对账记录卡片、状态标签、新建补录入口、导出按钮
2. **对账详情页**：基础信息、食材表与照片对照、禁忌匹配结果、状态流转时间线、改判操作
3. **手工补录弹窗**：录入家长信息、食材清单、异常说明，提交生成新记录
4. **摘要导出模块**：按当前筛选结果导出人类可读的文本摘要，供客服核对

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 对账列表页 | 顶部导航栏 | 产品名称、筛选框（手机号）、导出按钮、手工补录按钮 |
| 对账列表页 | 状态统计区 | 显示正常/异常/待改判/已改判 四类记录数量统计 |
| 对账列表页 | 记录列表 | 卡片展示宝宝姓名、家长手机号、对账日期、结果状态、禁忌条目数 |
| 对账详情页 | 基础信息卡 | 宝宝姓名、月龄、家长姓名、手机号、对账日期、提交方式（系统/手工） |
| 对账详情页 | 食材与禁忌对照区 | 左侧三日食材表、右侧餐盘照片占位、中间禁忌匹配高亮 |
| 对账详情页 | 状态时间线 | 完整展示每次状态变更（含原因）：初始提交→自动判定→人工改判→重复提交拦截→刷新回退等 |
| 对账详情页 | 改判操作区 | 异常改正常/正常改异常，需填写改判原因，提交后写入时间线 |
| 手工补录弹窗 | 表单区 | 家长信息、宝宝信息、食材清单、异常描述、照片上传（占位） |
| 导出摘要 | 文件内容 | 人类可读的文本格式，不含内部字段名，按手机号分组，含状态、禁忌、处理建议 |

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：奶粉绿 `#4CAF7A`（温和信任感）+ 珊瑚橙 `#FF7A59`（异常警示）
- **辅助色**：奶油米 `#FFFBF2` 背景 + 雾霾蓝 `#6B8BA8` 次要文字
- **按钮风格**：胶囊形圆角按钮，正常态微阴影，悬停态轻微上浮 + 阴影加深
- **字体**：标题使用 `Noto Serif SC`（衬线体，专业稳重），正文使用 `Noto Sans SC`（无衬线，易读）
- **布局风格**：卡片式布局，充足留白，状态标签使用带描边的色块 pill
- **图标风格**：使用 lucide-react 线性图标，保持统一粗细

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 对账列表页 | 顶部导航 | 左侧品牌名（衬线大字）+ 右侧筛选输入框、两个操作按钮 |
| 对账列表页 | 状态统计 | 四个等宽统计卡片，数字突出+状态文字，底色渐变对应状态 |
| 对账列表页 | 记录列表 | 垂直滚动卡片流，卡片左色条对应状态，信息分三行排列 |
| 对账详情页 | 双栏布局 | 左栏（60%）：食材对照 + 状态时间线；右栏（40%）：基础信息 + 改判操作 |
| 对账详情页 | 状态时间线 | 垂直时间轴，圆点为状态图标，节点下附变更原因说明文字 |
| 对账详情页 | 改判按钮组 | 两个并列主按钮（异常/正常），点击展开原因输入框 |
| 手工补录弹窗 | 模态框 | 居中型模态框，表单分区（家长/宝宝/食材/备注），底部操作按钮 |
| 导出摘要 | 下载触发 | 点击后 Toast 提示"正在生成... X 条记录"，完成后自动下载 |

### 4.3 响应式

- 桌面端优先（min-width: 1024px），两栏详情页
- 平板端（768-1023px）：详情页上下堆叠，列表卡片宽度自适应
- 移动端（< 768px）：单栏布局，筛选框移至顶部汉堡菜单内

### 4.4 动效说明

- 列表卡片进入：从下往上淡入 + 轻微位移（staggered 100ms）
- 状态标签 hover：背景色过渡 200ms
- 时间线节点：页面加载时从上至下依次点亮
- 模态框弹出：scale 0.95→1 + opacity 0→1，200ms ease-out
