# 婴幼儿睡眠观察清洗链 · 试听顾问版

面向早教课程顾问的婴幼儿睡眠观察全流程管理系统，覆盖**录入材料 → 提交复核 → 退回补充 → 关闭归档 → 导出**整条时间线，同时为家长提供简化表格视图，为主管提供完整审计能力。

---

## 一、角色与权限说明

| 角色 | 能做什么 | 看什么 |
|------|---------|-------|
| 课程顾问 (consultant) | 新建/编辑记录、提交复核、添加承诺/备注、换班、退回补充、归档、导出 | 所有自己处理过的记录，完整时间线 |
| 家长 (parent) | 查看最终结果 | **仅已归档的最终表格**，看不到中间流转 |
| 主管 (supervisor) | 所有顾问操作 + 查看审计日志 | 全部记录 + 越权访问审计 |

### 默认测试账号（密码统一为 `123456`）

## 二、安装 & 启动

### 环境要求
- Node.js ≥ 18
- npm 或 pnpm / yarn

### 步骤 1：安装依赖（首次运行）
在项目根目录执行：

```bash
npm run install:all
```

该命令会自动安装根目录、`server/`、`client/` 的全部依赖。

> 如遇 `better-sqlite3` 编译失败，请先执行 `npm install -g node-gyp` 并确保系统有 Python 3 和 C++ 编译工具链。

### 步骤 2：初始化样例数据
```bash
npm run seed
```
首次启动前执行即可（也可不执行，首次启动服务时会自动初始化）。控制台会打印默认账号信息。

### 步骤 3：启动开发环境（前后端同时启动）
```bash
npm run dev
```

启动成功后：
- 前端地址：http://localhost:3000
- 后端 API：http://localhost:3001/api

### 生产部署
```bash
npm run build   # 构建前端静态资源
npm start       # 启动后端（会同时托管前端 dist）
```
访问 http://localhost:3001 即可。

## 三、功能一览（顾问端）

登录后进入顾问工作台，按时间线推进流程：

### 1. 录入材料
点击右上角「+ 新建记录」，填写：
- 宝宝、班级（若该宝宝未在该班级，会自动建班籍）
- 观察标题、睡眠质量、睡眠时长、环境、已录入材料

保存后状态为**草稿**。

### 2. 提交复核
在记录详情页点击「提交复核」，状态从 `草稿` / `退回补充` → `复核中`。时间线上自动留痕。

### 3. 退回补充
当记录处于「复核中」时，顾问或主管可点击「退回补充」，填写：
- 退回原因（必填）
- 需补充字段（选填，提示顾问补什么）

退回后记录回到「退回补充」状态，同时生成一条退回记录。

### 4. 添加承诺 / 备注（家长临时改口时使用）
记录详情页 →「+ 备注/承诺」：
- **普通备注**：用于记录沟通信息
- **承诺**：勾选后标记为「承诺」，永久保留在历史中

> ✅ **核心设计**：家长临时改口时，**不要修改原来的承诺**，而是新建一条备注说明变更。原承诺不会被覆盖，时间线上用红色节点区分承诺（🔴）和普通备注（💬），主管复查时一目了然。

### 5. 跨班换班（同一宝宝允许部分成功）
记录详情页 →「换班」，选择目标班级即可。

系统会：
1. 尝试把宝宝加入新班级（若已存在则复用）
2. 把原班级状态改为「已转班」
3. 任一步失败都不会阻塞整体，返回「部分成功」提示，由主管在审计中核实。

### 6. 关闭归档
复核通过后点击「复核通过并归档」，状态变为 `已归档`，后续不可修改。

### 7. 导出
列表页或主管端点击「导出 Excel」，会下载包含三个 Sheet 的工作簿：
1. **睡眠观察记录** - 主表，含时间线和备注汇总
2. **时间线明细** - 每条记录的完整状态流转
3. **备注与承诺** - 承诺和备注分开标记

导出文件保存在 `server/exports/` 目录。

## 四、家长端怎么用（别让家长猜命令）

家长**不需要敲任何命令**，按以下步骤：

1. 打开 http://localhost:3000 （生产环境是部署后的域名）
2. 用账号 `parent1` / `123456` 登录（或顾问分配的账号）
3. 首页就是**宝宝睡眠观察汇总表** —— 只展示已归档的最终结果
4. 点击某一行的「查看详情」，只能看到最终归档时间节点，看不到中间的换班、退回、承诺变更等处理过程

## 五、触发异常 & 审计验证

### 1. 越权查看（会自动审计留痕）
操作步骤：
1. 用 `parent1` 登录
2. 把浏览器地址改成 http://localhost:3000/records/1（假设该记录属于顾问）
3. 系统返回「无权查看该记录（已留痕审计）」
4. 退出登录，用 `supervisor` 登录，进入「审计日志」标签页
5. 可以看到一条红色的 `unauthorized_view` 记录，带 IP 和用户信息

### 2. 换班部分成功
操作步骤：
1. 用顾问账号登录，给某个宝宝新建一条记录
2. 在详情页点击「换班」，选择新班级
3. 如果原班级状态修改失败或新班级插入异常，会弹出「换班部分成功，请核查原班级状态」
4. 主管在审计日志里会看到带 `partial` 标记的换班操作

### 3. 重复退回 / 错误状态流转
例如在「草稿」状态点击「退回补充」，后端会返回 400 错误，前端弹出提示，不会破坏时间线。

### 4. 查看所有审计日志
主管端「审计日志」页面可以看到：
- 正常操作：create / edit / submit / return / archive / view / export / note_add / transfer
- 越权操作：`unauthorized_view`、`unauthorized_access_attempt`（红色高亮）

## 六、查看导出文件

导出的 Excel 文件会自动触发浏览器下载，保存位置是浏览器的默认下载目录。

同时服务端也会在 `server/exports/` 目录保留一份副本，文件名格式：
```
sleep_observation_时间戳.xlsx
```

用 Excel / WPS / Numbers 打开即可查看三个 Sheet：
- Sheet 1「睡眠观察记录」：给家长或主管看的汇总
- Sheet 2「时间线明细」：完整处理留痕，方便复盘
- Sheet 3「备注与承诺」：承诺被单独标记出来，不会被后续备注覆盖

## 七、技术栈 & 项目结构

```
├── server/                # Node.js + Express + SQLite 后端
│   ├── index.js           # 服务入口
│   ├── db.js              # 数据库 Schema + 初始化样例数据
│   ├── auth.js            # JWT 认证 + 权限 + 审计工具函数
│   ├── routes/
│   │   ├── auth.js        # 登录接口
│   │   ├── records.js     # 记录 CRUD + 状态流转 + 换班
│   │   └── common.js      # 宝宝/班级/审计/导出/家长视图
│   ├── seed.js            # 手动初始化脚本
│   ├── data.db            # SQLite 数据库文件（首次运行自动生成）
│   └── exports/           # 导出的 Excel 文件存放目录
└── client/                # React + Vite 前端
    └── src/
        ├── pages/         # 登录/顾问/家长/主管/详情 5 个页面
        ├── App.jsx        # 路由 + 权限守卫
        ├── http.js        # axios 封装（自动带 token、401 跳转登录）
        └── styles.css     # 全局样式
```

核心数据模型：
- `records` 记录：含 `current_status` 状态机（draft → reviewing → returned → reviewing → archived）
- `timeline_events` 时间线：每次状态流转/编辑/备注都写一条，永不删除
- `notes` 承诺/备注：`is_promise=1` 的行永久保留，状态变更不会覆盖
- `baby_classes` 宝宝-班级关联：支持跨班、换班（`status=transferred` 保留历史）
- `audit_logs` 审计日志：越权访问自动记录

## 八、常见问题

**Q: 删掉 data.db 能重置吗？**  
A: 可以。停掉服务 → 删除 `server/data.db` 和 `server/data.db-*` → 重新执行 `npm run seed` 或直接启动服务即可。

**Q: 怎么加新用户？**  
A: 直接修改 `server/db.js` 里的 `initData()` 函数，或者用 SQLite 客户端（如 DB Browser for SQLite）打开 `server/data.db` 手动插入（密码要用 bcrypt 加密）。

**Q: 家长端能看到承诺吗？**  
A: 不能。家长端在详情页只显示 `action='archive'` 的最终节点，其他中间流程（包括承诺、备注、换班、退回）都过滤掉。
