# 能源绿证批次告警墙

面向售电公司结算员的绿证批次监控系统，解决创智园 A 座等项目绿证结算中出现的数据不一致、站点串站、权限泄露等实际业务痛点。

## 功能特性

- 📊 **三种内置数据场景**：正常数据、异常数据、空数据一键切换，无需导入外部文件
- 🔴 **导出数字与卡片对不上检测**：实时对比卡片显示与导出数据差异
- 🟡 **站点同名串站检测**：自动识别"创智园 A 座"等同名站点归属冲突
- 🟠 **权限视图泄露检测**：监控手机号等敏感信息未脱敏风险
- 📝 **周顾问手工补录**：内置证书扫描件补录流程，支持补录前后差异对比
- 💾 **导出读回验证**：支持 JSON 导出并验证数据一致性
- ✨ **深色工业风设计**：毛玻璃效果、脉冲告警动画、流畅过渡动效

## 内置样例数据说明

- **操作员**：王结算

#### 3. 权限视图泄露手机号（批次 LC-2026-001）
- **站点**：科技园 B 座
- **问题**：手机号 `13800131234` 未脱敏显示

## 触发导出数字与卡片对不上操作指南

### 步骤 1：切换到异常数据场景
```
右侧"数据场景切换" → 点击"异常数据"
```

### 步骤 2：定位异常批次
```
找到批次卡片"创智园 A 座（LC-2026-003）
→ 红色边框 + 红色感叹号图标
→ 卡片上直接显示"导出: 128 / 卡片: 132 ↓4"
```

### 步骤 3：查看详细差异
```
点击该批次卡片
→ 右侧滑出详情面板
→ 顶部红色区域显示"导出数字与卡片对不上"
→ 查看对比表格：
  ├─ 证书数量：卡片 132 / 导出 128 / 差值 -4
  └─ 结算金额：卡片 ¥52,800 / 导出 ¥51,200 / 差值 -¥1,600
→ 查看原因说明：系统接口超时导致 4 张证书数据未同步
```

### 步骤 4：触发重新导出验证
```
点击"重新导出并验证差异"按钮
→ 控制台打印导出数据
→ 可点击"导出 JSON"下载完整数据文件
→ 打开下载的 JSON 文件，确认 exportCount 字段为 128
```

### 步骤 5：数据对比总览
```
详情面板向下滚动到"数据对比总览"
→ 左侧绿色卡片显示卡片数据
→ 右侧红色卡片显示导出数据
→ 下方红色区域显示差异数量和金额
```

## 周顾问手工补录证书操作指南

### 步骤 1：选择批次
```
点击任意批次卡片（推荐选择正常数据或异常数据中的批次）
→ 进入详情面板
```

### 步骤 2：进入补录面板
```
点击详情面板右下角"周顾问补录"按钮
→ 滑出补录面板
→ 显示周顾问身份信息和当前批次数据
```

### 步骤 3：查看内置扫描件
```
证书扫描件区域已自动关联内置扫描件
→ 可看到 GC-2026-ZHOU-001
→ 电量 125.50 MWh
→ 补录金额 ¥50,200
```

### 步骤 4：填写补录说明
```
在"补录说明"文本框输入说明
例：系统漏传，周顾问现场核对原件后手工补录
```

### 步骤 5：执行补录
```
点击"确认补录证书"按钮
→ 按钮变为"已完成补录"
→ 下方自动展开"补录前后差异对比"表格
```

### 步骤 6：查看补录差异
```
对比表格展示三列数据：
  ├─ 补录前：证书 78 张，金额 ¥31,200
  ├─ 补录后：证书 79 张，金额 ¥81,400
  └─ 导出读回：证书 79 张，金额 ¥81,400
→ 显示"✅ 一致性验证：补录后数据与导出读回数据完全一致"
```

### 步骤 7：查看扫描件
```
点击"查看扫描件"按钮
→ 展开显示证书扫描件完整 SVG
→ 可看到补发标识、补录人、补录时间、业务章等信息
```

### 步骤 8：导出读回验证
```
点击"导出差读回数据（JSON）"按钮
→ 下载 JSON 文件
→ 打开文件可看到 consultantNote 字段带有"[导出读回]"前缀
→ 验证数据完整性
```

### 步骤 9：返回详情查看补录结果
```
点击左上角"返回详情"
→ 详情面板新增"手工补录证书"区域
→ 显示补录的证书信息和扫描件预览
→ 卡片底部顾问备注已更新
```

## 异常场景设计考量

本项目特别针对真实业务痛点设计，拒绝只跑通干净数据：

1. **导出数字与卡片对不上**：模拟系统接口超时、数据同步失败场景
2. **站点同名串站**：模拟多项目重名、数据归属错误场景
3. **权限视图泄露**：模拟权限配置错误、敏感信息泄露场景
4. **手工补录流程**：模拟异常数据修正、审计追踪场景
5. **导出读回验证**：模拟数据一致性校验场景

## 常见问题

**Q: 为什么默认进入显示的是哪种数据？
A: 默认进入"异常数据"场景，可直接看到所有异常场景。

**Q: 切换场景后数据会重置吗？
A: 是的，每次切换场景都会重置为该场景的初始数据。

**Q: 补录的数据会保存吗？
A: 补录操作保存在内存中，刷新页面后会重置。

**Q: 导出的 JSON 文件在哪里？
A: 下载到浏览器默认下载目录，文件名格式：`批次号_类型_时间戳.json`。

**Q: 手机号为什么有的显示完整有的打码？
A: 这是故意设计的权限泄露场景，用于测试权限视图配置检测。
