## 1. 产品概述

屋面找坡排查页——面向屋面工程师的单页应用，将测点高程、排水方向、雨后照片与返工建议汇聚同一界面，支持分区切换、坡度自动计算、风险说明、版本追踪与导出摘要，实现从数据录入到返工决策的全链路闭环。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 屋面工程师 | 直接访问 | 录入/编辑测点、查看坡度计算、上传雨后照片、编写返工建议、导出摘要 |
| 项目经理 | 通过导出文件查看 | 查看导出摘要、通过链接回溯测点 |

### 2.2 功能模块
1. **主排查页**：分区切换、测点网格、坡度计算面板、雨后证据区、返工建议编辑器、版本历史
2. **导出摘要面板**：筛选条件联动、一键导出、测点回溯链接

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主排查页 | 分区切换栏 | 下拉/标签切换屋面分区，切换后测点网格、坡度、证据、建议联动刷新 |
| 主排查页 | 测点网格 | 以网格形式展示测点高程数据，支持编辑、新增、删除；空测点显示"未录入"提示；单位切换(cm↔mm)自动换算 |
| 主排查页 | 坡度计算面板 | 根据相邻测点高程差与距离自动计算坡度，标注坡度方向箭头；不满足最小坡度要求时高亮风险 |
| 主排查页 | 雨后证据区 | 展示雨后积水照片和积水描述，支持上传照片和文字标注；标记"补录"状态 |
| 主排查页 | 返工建议编辑器 | 编写和修改返工建议，保存时自动创建新版本；支持查看历史版本和版本间差异比较 |
| 主排查页 | 版本历史面板 | 时间线形式展示返工建议的修改历史，点击可查看该版本完整内容，支持两版本并排比较 |
| 导出摘要面板 | 筛选联动 | 根据当前分区筛选条件和风险等级过滤内容，筛选变化时导出内容实时更新 |
| 导出摘要面板 | 一键导出 | 生成包含风险摘要、坡度异常、返工建议的导出文档；测点编号可链接回原测点 |

## 3. 核心流程

用户打开页面 → 选择屋面分区 → 查看测点网格和坡度计算 → 查看雨后照片证据 → 编写/修改返工建议 → 查看建议版本历史 → 调整筛选条件 → 导出摘要给项目经理

```mermaid
flowchart TD
    "A[打开页面]" --> "B[选择屋面分区]"
    "B" --> "C[查看测点网格]"
    "C" --> "D[查看坡度计算]"
    "D" --> "E[查看雨后证据]"
    "E" --> "F[编写/修改返工建议]"
    "F" --> "G[版本自动保存]"
    "G" --> "H{需要查看历史?}"
    "H" --> "是" --> "I[版本比较]"
    "H" --> "否" --> "J[调整筛选条件]"
    "I" --> "J"
    "J" --> "K[导出摘要]"
    "K" --> "L[项目经理通过链接回溯测点]"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色：深钢蓝(#1B2A4A)，辅色：冷灰(#64748B)
- 强调色：琥珀黄(#F59E0B)表示风险警告，珊瑚红(#EF4444)表示严重超标
- 安全色：翡翠绿(#10B981)表示坡度合格
- 按钮：圆角矩形，微弱投影，hover态加深背景
- 字体：数据区使用 JetBrains Mono，UI文本使用 DM Sans
- 布局：左侧测点网格+坡度面板，右侧雨后证据+返工建议，顶部工具栏
- 图标：lucide-react 图标库

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主排查页 | 顶部工具栏 | 分区选择下拉、单位切换开关、筛选条件、导出按钮；深色背景，浅色文字 |
| 主排查页 | 测点网格 | 网格表格，单元格显示高程值，空测点虚线框+提示文字，单位标签跟随切换 |
| 主排查页 | 坡度计算面板 | 箭头指示排水方向，数值标注坡度百分比，超标红色高亮，合格绿色标记 |
| 主排查页 | 雨后证据区 | 照片卡片流，每张附带时间戳和积水描述，补录记录带"补录"角标 |
| 主排查页 | 返工建议编辑器 | 富文本编辑区，保存按钮，版本号显示，编辑时自动锁定 |
| 主排查页 | 版本历史 | 左侧时间线，版本节点可点击，选中版本内容在右侧展示 |
| 导出摘要面板 | 筛选联动区 | 风险等级多选、分区多选，实时过滤预览 |
| 导出摘要面板 | 导出预览 | 紧凑排版摘要，测点编号可点击锚点，下载按钮 |

### 4.3 响应式
- 桌面优先设计，最小宽度 1280px
- 大屏(>1600px)侧栏展开更多细节
- 平板(768-1280px)右侧面板折叠为底部抽屉
