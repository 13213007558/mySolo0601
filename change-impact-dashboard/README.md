# 设计变更影响对照页

管理设计变更对工序、成本和已施工区域的影响分析系统。

## 技术栈

- **Vue 3** - 前端框架
- **Pinia** - 状态管理
- **Vite** - 构建工具
- **Tailwind CSS** - 样式框架
- **Lucide Vue** - 图标库
- **SheetJS (xlsx)** - Excel 导入导出
- **localStorage** - 浏览器本地存储

## 项目特点

- ✅ **楼层联动**：切换楼层时自动更新成本、进度、责任专业统计
- ✅ **已施工标记**：清晰区分已施工、部分施工、仅图纸三种状态
- ✅ **撤回机制**：误判后可撤回，旧数据和处理人保留在历史记录
- ✅ **版本对比**：支持多版本变更管理和差异对比
- ✅ **导入去重**：重复的变更编号自动跳过
- ✅ **刷新读回**：筛选条件、待确认数量、导出表刷新后保持不变
- ✅ **数据哈希**：一致性验证确保数据未被篡改

## 施工状态说明

| 状态 | 颜色 | 说明 |
|------|------|------|
| 已施工 | 🔴 红色边框 | 该区域已完成施工，变更会产生返工成本 |
| 部分施工 | 🟡 黄色边框 | 该区域正在施工，变更需要调整工序 |
| 仅图纸 | 🔵 蓝色边框 | 该区域尚未施工，变更仅影响图纸 |

## 影响等级说明

| 等级 | 颜色 | 说明 |
|------|------|------|
| 高影响 | 🔴 红色 | 成本增加 >5万 或 工期延误 >3天 |
| 中影响 | 🟡 黄色 | 成本增加 1-5万 或 工期延误 1-3天 |
| 低影响 | 🟢 绿色 | 成本增加 <1万 或 工期延误 <1天 |
| 无影响 | ⚪ 灰色 | 仅图纸调整，不影响施工 |

## 处理状态说明

| 状态 | 说明 |
|------|------|
| 待确认 | 变更已录入，等待专业工程师确认影响 |
| 已确认 | 变更影响已确认，等待执行 |
| 已驳回 | 变更成本过高或不可行，建议优化 |
| 已撤回 | 之前的判断有误，已修正 |
| 已执行 | 变更已落实到施工或图纸中 |

## 数据存储说明

- 所有数据存储在浏览器 **localStorage** 中
- 包括：变更数据、筛选条件、当前选中楼层
- 清理浏览器数据会导致数据丢失
- 建议定期导出 Excel 备份

## 浏览器兼容性

- Firefox 88+

## 注意事项

1. **纯前端项目**：不依赖任何后端服务，所有功能在浏览器端完成
2. **数据安全**：定期导出 Excel 备份重要数据
3. **刷新验证**：重要操作后建议刷新页面验证数据一致性
4. **撤回机制**：撤回后旧数据不会删除，会保留在历史记录中用于审计
5. **版本管理**：设计院补发新版变更函时，使用版本对比功能查看差异
