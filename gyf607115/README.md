# 能源BMS告警对账系统

资产移交库BMS告警全生命周期管理工具，解决传统表格记录存在的权限视图泄露手机号、对账困难、状态跟踪混乱等问题。

---

## 🚀 快速启动

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

启动成功后，访问终端显示的本地地址（通常是 `http://localhost:5173`）即可打开应用。

> **注意**：不要只看到 "运行成功" 就结束，继续往下看如何体验完整功能。

---

## 📖 如何查看样例

应用启动后，首页自动加载30+条模拟告警数据，包含以下特意设计的样例场景：

### 🎯 样例1：README命令与页面不一致

**目标**：验证系统能否检测到命令行输出与页面显示的数据不一致。

**触发方法**：

1. 打开应用首页，观察顶部的校验提示横幅
2. 找到告警编号为 `BMS-READM-001` 的记录（ID: `alarm-readme-001`）
3. 在终端执行以下命令：
   ```bash
   npm run check-alarm -- alarm-readme-001
   ```
4. 观察命令行输出与页面显示的差异：
   - **命令行输出**：`描述: README命令测试告警-命令行版本`
   - **页面显示**：`描述: README命令测试告警-页面显示版本`
5. 点击页面顶部校验横幅中的「展开」按钮，查看详细的不一致报告
6. 点击「一键修复」按钮，系统会自动同步数据

**在页面上也可以直接演示**：点击顶部导航栏的「执行README命令」按钮，会弹出终端模拟窗口，直观展示两者差异。

---

### 🎯 样例2：小数精度导致金额算偏

**目标**：验证浮点数累加导致的精度问题是否被正确检测。

**触发方法**：

1. 打开应用首页，观察顶部统计卡片中的「涉及金额」
2. 仔细查看金额下方的提示文字：
   - 页面显示总金额（四舍五入累加）：`¥xxx.xx`
   - 精确计算总金额（先乘后除累加）：`¥xxx.xx`
   - 差额：`¥0.0001` 或其他微小数值
3. 查看校验提示横幅中的「小数精度问题」警告
4. 这是由于10条 `0.1` 和 `0.2` 交替累加导致的经典浮点数精度问题：
   ```javascript
   0.1 + 0.2 = 0.30000000000000004  // 经典问题
   ```
5. 点击「导出数据」，在导出预览中可以看到：
   - 显示金额列（四舍五入后的值）
   - 精确金额列（保留4位小数的真实值）
   - 底部合计同时展示两种计算结果，并标注是否存在偏差

---

### 🎯 样例3：手机号脱敏检测

**目标**：验证系统能否检测到未脱敏的手机号，避免敏感信息泄露。

**触发方法**：

1. 打开应用首页，查看告警列表中的「联系人」列
2. 找到告警编号为 `BMS-LEAK-001` 的记录（ID: `alarm-leak-001`）
3. 观察其联系人显示为完整手机号 `13800138001`（未脱敏）
4. 而 `BMS-LEAK-002` 和 `BMS-LEAK-003` 显示为 `139****002`、`137****003`（已脱敏）
5. 查看校验提示横幅中的「手机号泄露」错误
6. 点击「一键修复」，系统会自动对所有未脱敏手机号进行 `138****1234` 格式脱敏
7. 进入任意告警详情页，在右侧「数据一致性校验」面板可以看到：
   - 手机号脱敏状态：✓ 已脱敏 / ✗ 未脱敏

---

### 🎯 样例4：孟经理手工补录BMS屏幕拍照

**目标**：验证手工补录流程、图片上传、差异对比、导出读回功能。

**触发方法**：

1. 点击首页顶部导航栏右侧的「孟经理手工补录」按钮（橙色相机图标）
2. 进入手工补录页面，可以看到：
   - BMS屏幕拍照上传区域（支持拖拽或点击上传）
   - 补录类型选择：新增告警 / 补充修正现有告警
   - 告警信息表单
3. **查看已有的补录样例**：
   - 在首页告警列表中找到 `BMS-MANUAL-001`（来源显示为「手工补录」带相机图标）
   - 点击进入详情页
   - 可以看到「BMS屏幕拍照」区域显示的现场照片
   - 下方「手工补录信息」区域展示：
     - 补录人：孟经理
     - BMS屏幕拍照图片
     - 补录备注
     - **补录前后差异对比**：红色标注修改的字段（金额、级别、描述）
4. **导出读回验证**：
   - 勾选该条告警，点击「导出数据」
   - 在导出预览中可以看到补录的图片URL和差异说明
   - 导出CSV/JSON后，重新导入（或查看文件内容）验证数据完整性

5. **亲自体验补录流程**：
   - 回到手工补录页面
   - 上传一张测试图片
   - 选择「补充/修正现有告警」，选择任意一条已有告警
   - 修改金额或描述字段
   - 系统会自动高亮显示差异字段
   - 填写补录备注
   - 点击「保存补录」
   - 系统自动跳转至详情页，查看补录结果

## 📊 主要功能一览

| 功能模块 | 说明 |
|---------|------|
| 🔍 可筛选清单 | 按告警级别、状态、站点、时间范围、关键词多条件筛选 |

| 📤 数据导出 | 支持CSV/JSON格式，导出前预览，包含精度说明和差异记录 |
| 📷 手工补录 | 孟经理专用入口，支持BMS屏幕拍照上传、差异对比 |

## 🧪 如何验证校验功能

### 验证README不一致

1. 执行 `npm run check-alarm -- alarm-readme-001`，记录输出的描述字段
2. 在页面上找到同一条告警，对比描述字段
3. 确认页面顶部显示「README命令与页面不一致」错误
4. 点击「一键修复」
5. 重新执行命令并刷新页面，确认两者一致
6. 确认校验提示消失

### 验证小数精度

1. 查看首页顶部「涉及金额」卡片
2. 记录页面显示的总金额
3. 点击「导出数据」，查看导出预览中的精确计算总金额
4. 确认两者存在微小差异（约0.0001）
5. 确认校验提示中显示「小数精度导致金额计算偏差」警告

### 验证手机号脱敏

1. 在列表中找到 `BMS-LEAK-001`，确认显示完整手机号
2. 确认校验提示中显示「检测到1条手机号未脱敏」错误
3. 点击「一键修复」
4. 确认该告警联系人变为 `138****8001`
5. 进入详情页，确认右侧「手机号脱敏」显示为 ✓ 已脱敏

### 验证补录前后差异和导出读回

1. 进入 `BMS-MANUAL-001` 详情页
2. 查看「手工补录信息」中的差异对比
3. 记录差异字段（金额从25000→28500，级别从warning→critical）
4. 勾选该告警，导出为JSON
5. 打开导出的JSON文件，确认包含：
   - `bmsPhotoUrl` 字段（图片地址）
   - `validationNotes.diffData` 字段（差异记录）
   - `summary.amountMismatch` 字段（精度警告）

## 🎨 设计特点

- **工业风UI**：深蓝主色调，等宽字体显示编号和金额，适合专业运维场景
- **动效细节**：统计数字滚动动画、卡片悬停上移、状态指示灯呼吸效果
- **数据可视化**：校验结果用不同颜色区分严重程度，差异对比左右分栏高亮显示
- **响应式布局**：桌面端三栏布局，移动端自适应单列

---

## ⚠️ 注意事项

1. **样例数据设计**：本系统特意设计了数据不一致问题用于校验功能演示，**请勿直接用于生产环境**
2. **浮点数精度**：金额计算建议使用 `decimal.js` 等精确计算库替代原生浮点数运算
3. **手机号脱敏**：生产环境应在后端API层统一处理脱敏，前端脱敏仅用于展示
4. **数据持久化**：当前使用浏览器LocalStorage + 内存Mock数据，生产环境需接入真实后端
