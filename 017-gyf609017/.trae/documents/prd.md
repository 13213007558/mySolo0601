## 1. 产品概述

门窗进场验收台——面向材料员的门窗进场全流程管理工具。解决洞口编号混乱、五金缺件漏记、补货无追溯等现场痛点，将批次验收、缺件登记、补货闭环和移交清单串联在前端可操作流程中。

- 目标用户：施工现场材料员、监理、甲方验收人员
- 核心价值：杜绝缺件漏记、补货无跟踪，交付清单一键导出，刷新后数据不丢失

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 材料员 | 默认角色 | 录入/编辑门窗记录、登记缺件、记录补货、导出清单 |
| 责任人 | 交接指定 | 查看全部记录、确认补货、导出清单 |

### 2.2 功能模块

1. **仪表盘**：统计概览（批次数、待验收、缺件数、已补货数）、近期批次列表、待处理缺件提醒
2. **进场登记**：扫码/手工录入门窗记录，关联批次和洞口编号，支持重复到货标记
3. **缺件管理**：五金缺件登记（含照片上传）、补货状态流转、历史变更记录
4. **补货记录**：补货时间线、责任人变更、补货数量确认
5. **导出中心**：按楼栋/户号分组的移交清单 CSV 导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 仪表盘 | 统计卡片 | 批次总数、待验收数、缺件总数、已补货数 |
| 仪表盘 | 近期批次 | 最近5个批次的验收进度一览 |
| 仪表盘 | 待处理提醒 | 未补货缺件列表，点击跳转补货 |
| 进场登记 | 批次管理 | 新建批次、选择已有批次、批次列表 |
| 进场登记 | 门窗录入 | 洞口编号（自动大写归一化）、规格、玻璃类型、五金清单 |
| 进场登记 | 重复到货检测 | 同一洞口编号重复到货时高亮提示 |

| 缺件管理 | 变更历史 | 每次状态变更记录时间、操作人、备注 |

| 导出中心 | CSV 导出 | 一键下载，字段含洞口编号、规格、缺件明细 |

## 3. 核心流程

材料员扫码或手工录入门窗进场信息，系统自动归一化洞口编号并检测重复到货。验收时发现五金缺件，登记缺件并拍照。后续补货到齐后更新状态，所有变更自动记录历史。交付前按楼栋户号导出移交清单。交接时可指定新责任人，刷新后历史和统计保持完整。

```mermaid
    "批次验收" --> "五金检查"

    "是否缺件?" --> "登记缺件+拍照"
    "登记缺件+拍照" --> "补货到齐"

    "是否缺件?" --> "验收完成"
    "更新状态+记录历史" --> "验收完成"
    "验收完成" --> "导出移交清单"
    "导出移交清单" --> "交接责任人"
```

## 4. 用户界面设计

### 4.1 设计风格

- **风格定位**：工业实用风（Industrial Utility）——深色侧边栏 + 浅灰内容区，数据密度优先
- **主色**：钢蓝 #3B6A9C（信任感、工业感）
- **辅色**：琥珀 #D97706（缺件警告）、翠绿 #059669（已补齐确认）
- **危险色**：铁红 #DC2626（重复到货、关键缺件）
- **字体**：Source Sans 3（标题）/ Noto Sans SC（中文正文）
- **布局**：左侧固定导航栏 + 右侧内容区，卡片式模块
- **按钮**：圆角4px，hover 轻微上浮阴影，主按钮实色填充
- **图标**：Lucide Icons 线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 仪表盘 | 统计卡片 | 4列网格，数字大号加粗，底部趋势线 |
| 仪表盘 | 近期批次 | 紧凑表格，进度条显示验收完成率 |
| 仪表盘 | 待处理提醒 | 列表卡片，琥珀色左侧边框，点击跳转 |
| 进场登记 | 表单区 | 两栏布局，洞口编号输入框带自动大写转换提示 |
| 进场登记 | 重复提示 | 顶部横幅，铁红色背景，显示已有记录链接 |
| 缺件管理 | 缺件列表 | 分组表格，按状态标签筛选 |
| 缺件管理 | 状态徽章 | 缺件(红)、部分补货(琥珀)、已补齐(绿) |
| 补货记录 | 时间线 | 垂直时间线，节点含时间戳和操作描述 |
| 导出中心 | 预览区 | 按楼栋折叠分组，树形结构预览 |
| 导出中心 | 导出按钮 | 主按钮，点击即下载 CSV 文件 |

### 4.3 响应式

- 桌面优先（1440px 基准）
- 平板适配（768px+）：侧边栏折叠为图标模式
- 手机（<768px）：底部标签导航，表单单栏布局
