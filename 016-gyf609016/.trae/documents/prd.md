## 1. 产品概述

外立面石材色差复核板——为外装施工员提供石材到货验收、色差分级拍照、分区铺贴决策与替换记录追溯的一体化工具。核心解决"上午到场、下午上墙"的高时效场景下，色差判断无据可依、替换历史不可追溯、照片与批次脱节的问题。

- 目标用户：外装施工员、项目质检员
- 核心价值：色差分级可筛选、替换记录可追溯、铺贴建议可导出、操作变更有审计

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 施工员 | 输入姓名即可使用 | 录入、编辑、导出 |
| 质检员 | 输入姓名即可使用 | 查看复核、确认替换 |

### 2.2 功能模块

1. **石材复核列表页**：批次筛选、立面分区筛选、色差等级筛选、统计面板、批量操作
2. **石材详情页**：照片附件查看/上传、替换建议、现场确认、操作历史时间线

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 石材复核列表 | 筛选栏 | 按批次号、立面分区、色差等级多条件筛选，支持照片缺失标记 |
| 石材复核列表 | 统计面板 | 各色差等级数量、缺失照片数、已确认/待处理数 |
| 石材复核列表 | 数据表格 | TanStack Table 展示石材记录，支持行选择、批量分区调整 |
| 石材复核列表 | 批量操作栏 | 批量修改分区、批量标记色差等级、导出铺贴建议 |
| 石材详情 | 基本信息卡 | 批次号、石材编号、当前分区、色差等级、上墙状态 |
| 石材详情 | 照片附件区 | 原照片查看、上传新照片、标记照片缺失 |
| 石材详情 | 替换建议区 | 替换建议文本、替换目标石材、替换原因 |
| 石材详情 | 现场确认区 | 确认人、确认时间、确认结果（通过/不通过/待确认） |
| 石材详情 | 操作历史 | 时间线展示所有变更记录，含操作人、操作时间、变更内容 |

## 3. 核心流程

施工员到场验收流程：石材到场 → 拍照录入 → 按批次色差分组 → 标记色差等级 → 分配立面分区 → 生成铺贴建议 → 导出确认

异常处理流程：发现色差 → 标记问题等级 → 提出替换建议 → 现场确认 → 执行替换 → 记录追溯

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：暖石灰 #8B8680（呼应石材质感），强调色：赤陶 #C4704A（标记问题/替换）
- 按钮风格：圆角微阴影，主操作实心填充，次操作线框
- 字体：Noto Serif SC（标题）+ Noto Sans SC（正文），标题18px/正文14px
- 布局风格：左侧导航+主内容区，卡片式信息分组
- 图标风格：Lucide 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 石材复核列表 | 筛选栏 | 下拉选择器×3，搜索框，清除筛选按钮 |
| 石材复核列表 | 统计面板 | 4个统计卡片，色差等级用颜色区分 |
| 石材复核列表 | 数据表格 | 行选择checkbox，排序表头，行内色差等级标签 |
| 石材复核列表 | 批量操作栏 | 浮动操作条，分区下拉、等级下拉、导出按钮 |
| 石材详情 | 基本信息卡 | 上方大卡片，状态标签右上角 |
| 石材详情 | 照片附件区 | 网格缩略图，点击放大，缺失标记红色虚线框 |
| 石材详情 | 替换建议区 | 表单+历史替换记录列表 |
| 石材详情 | 现场确认区 | 三态按钮组，确认人+时间 |
| 石材详情 | 操作历史 | 左侧时间线，右侧变更内容卡片 |

### 4.3 响应式

桌面优先设计，最小宽度1280px。表格区域支持水平滚动。

### 4.4 3D 场景

不适用
