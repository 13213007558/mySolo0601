## 1. 产品概述

婴幼儿辅食禁忌夜班交接系统，用于托育机构夜班老师在早会前核对婴幼儿辅食禁忌、三日食材表与实际备餐情况，确保厨房未按过期禁忌表备料。通过内置样例覆盖正常、异常、人工改判三条验证路径，并支持手工补录与摘要导出。

- 核心目标：避免因辅食禁忌信息滞后导致的食品安全事故，确保夜班到白班的交接清晰可追溯
- 目标用户：托育机构夜班老师、白班老师、厨房备餐人员

## 2. 核心功能

### 2.1 用户角色
| 角色 | 描述 | 核心权限 |
|------|------|----------|
| 夜班老师 | 系统主要使用者，早会前核对并交接 | 查看记录、标记异常、人工改判、手工补录、导出摘要 |
| 白班老师/厨房 | 接收交接信息 | 查看记录、查看导出摘要 |

### 2.2 功能模块
1. **交接本首页**：宝宝辅食禁忌记录列表、状态筛选（正常/异常/待复核）、统计概览、操作入口
2. **记录详情页**：单条宝宝记录完整信息、禁忌匹配校验详情、正常/异常原因说明、单位混用与边界值提示、人工改判操作
3. **手工补录页**：补录遗漏的宝宝辅食禁忌记录，标记补录来源与时间
4. **摘要导出**：生成友好可读的交接摘要，可直接转发同事

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 交接本首页 | 顶部统计区 | 显示宝宝总数、正常数、异常数、待复核数、补录数 |
| 交接本首页 | 筛选与搜索 | 按状态筛选、按宝宝姓名搜索、按日期切换 |
| 交接本首页 | 记录列表 | 卡片式列表，展示宝宝姓名、年龄、禁忌状态标签、今日食材匹配结果 |
| 交接本首页 | 操作入口 | 手工补录按钮、导出摘要按钮、刷新校验按钮 |
| 记录详情页 | 宝宝基础信息 | 姓名、月龄、过敏史、建档时间、补录标记 |
| 记录详情页 | 禁忌清单 | 过敏原、禁忌食材、可食用食材、最大摄入量 |
| 记录详情页 | 今日匹配校验 | 三日食材表与禁忌逐条比对，每条显示匹配结果与原因 |

| 摘要导出 | 预览与导出 | 生成人类可读摘要，区分正常/异常宝宝，突出重点风险项 |

## 3. 核心流程

### 3.1 主流程描述
夜班老师登录系统 → 查看当日交接本记录列表 → 系统自动比对三日食材表与各宝宝禁忌清单 → 浏览正常记录确认无误 → 进入异常记录详情查看原因 → 对疑似误判记录进行人工改判 → 手工补录遗漏的宝宝记录 → 全量复核后导出交接摘要 → 转发给白班老师和厨房

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深墨绿 #1F4D3D（专业、稳重、医疗感），搭配暖橙 #E8A87C（警示、提醒）
- **辅助色**：米白背景 #F5F1EA，状态色：正常绿 #3A7D5C、异常红 #C25B56、待复核橙 #D4915A、补录蓝 #4A6FA5
- **按钮风格**：圆角 10px，微阴影，hover 轻微上浮
- **字体**：标题用 Noto Serif SC（典雅可读），正文用 Noto Sans SC（清晰专业）
- **布局风格**：卡片式布局，柔和阴影，充足留白，强调信息层级
- **图标风格**：线性简约图标，搭配圆角色块状态徽章

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 交接本首页 | 顶部统计区 | 大字号数据卡，状态色区分，渐入动画 |
| 交接本首页 | 记录卡片列表 | 左对齐宝宝信息，右侧状态徽章，底部食材匹配摘要，hover 轻微放大 |
| 交接本首页 | 操作栏 | 左对齐筛选按钮组，右对齐主操作按钮 |
| 记录详情页 | 信息分区 | 分区标题左侧竖条装饰色，分区内信息网格布局 |
| 记录详情页 | 校验明细 | 逐条展开的校验项，正常/异常图标前缀，原因说明小字 |
| 记录详情页 | 人工改判区 | 警示边框表单，原因输入框必填，改判按钮带确认弹窗 |
| 手工补录页 | 表单 | 分组表单，必填项红星标记，底部双按钮（取消/保存） |
| 摘要导出 | 预览弹窗 | 模拟纸张效果，白底黑字，分节清晰，一键复制按钮 |

### 4.3 响应式
- 桌面端优先（1280px+），主内容区最大宽度 1200px 居中
- 平板端（768-1279px）：卡片改为两列，统计卡自适应换行
- 移动端（<768px）：卡片单列，操作栏折行，详情页分区堆叠

## 5. 内置样例数据规范

系统启动后内置以下样例记录，覆盖三条核心路径：

### 5.1 正常路径样例（2条）
- **宝宝A**：8月龄，鸡蛋过敏，三日食材表无鸡蛋，全量匹配正常
- **宝宝B**：14月龄，坚果过敏，最大花生摄入量 0g，食材表无坚果，正常

### 5.2 异常路径样例（2条）
- **宝宝C**：10月龄，牛奶蛋白过敏（标注单位 ml），食材表出现「奶油 50g」——单位混用（ml vs g），系统标记异常，详情页注明"单位不一致需人工复核：禁忌以 ml 计量，食材以 g 录入"
- **宝宝D**：12月龄，芒果过敏，最大摄入量 0g，食材表出现「芒果丁 1g」——边界值 0g 与 1g 触发，系统标记异常，详情页注明"边界值触发：禁忌最大摄入量为 0g（完全禁食），食材含 1g"

### 5.3 人工改判路径样例（1条，初始状态为异常待改判）
- **宝宝E**：11月龄，海鲜过敏，食材表出现「虾粉调味料 0.1g」——系统标记异常，但实际为极微量调味且该宝宝已耐受，可人工改判为正常，改判后记录改判原因

### 5.4 手工补录样例（1条，展示补录前后）
- **宝宝F**：9月龄，小麦过敏——初始不在列表中，通过手工补录添加，补录后带「补录」标签，详情页显示补录时间与补录原因

### 5.5 坏数据隔离验证
- 内置一份"旧记录"（2条：含一条正常一条异常）和一份"新材料"，验证导入新材料时坏行不影响已有正常宝宝的状态
