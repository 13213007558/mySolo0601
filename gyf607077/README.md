# 🌙 婴幼儿睡眠观察复核墙 · 家庭协作版

> 录入 → 提交 → 退回补充 → 关闭归档 · 一条时间线全留痕

专为家庭育儿协作 + 客服主管复核 的睡眠观察记录系统。所有操作都在时间线上可追溯，支持主管复查。

---

## 🏗️ 技术栈

- 后端: Node.js + Express + better-sqlite3 (SQLite 文件库，无需额外安装数据库
- 前端: React 18 + Vite
- 认证: JWT
- 导出: CSV

---

## 📦 一、安装依赖

在项目根目录执行 **一次** 即可（使用 npm workspaces 一键安装根目录、后端、前端的所有依赖：

```bash
npm run install:all
```

> 如果你想单独安装，也可以：

- 根目录: `npm install`
- backend: `cd backend && npm install`
- frontend: `cd frontend && npm install`

---

## 🚀 二、启动服务

### 开发模式（前后端同时启动，热更新）

```bash
npm run dev
```

启动后会同时启动两个进程：
- 后端 API: http://localhost:4000
- 前端页面: http://localhost:5173

浏览器打开 **http://localhost:5173** 即可。

### 生产模式（先构建前端再启动后端，后端直接 serve 前端静态文件）

```bash
npm run build
npm start
```

打开 **http://localhost:4000**。

## 👥 四、角色与信息边界

| 角色 | 能看到什么 | 能做什么 |
|---|---|---|
| 👵 **老人 (elder)** | 仅摘要卡片（宝宝+日期+质量一句话） | 只读摘要列表 |
| 🧑 **育儿嫂 (nanny)** | 完整详情 + 完整时间线 | 录入、编辑自己的记录、提交复核 |
| 👨‍👩‍👧 **父母 (parent)** | 完整详情 + 完整时间线 | 录入、提交、退回、归档、导出 CSV |
| 👩‍💼 **客服主管 (supervisor)** | 所有记录 + 完整时间线 + **审计日志** | 全部操作 + 状态回退 + 导出 + 查看审计 |

## 🔄 五、核心流程（一条时间线）

1. **录入材料**（育儿嫂或父母）→ 状态 `草稿`
2. **提交复核** → 状态 `已提交待复核`
3. **退回补充**（主管/父母，需填写退回原因）→ 状态 `已退回补充`
4. **再次提交** → `已提交待复核`
5. **关闭归档**（主管/父母）→ 状态 `已关闭归档`

**所有步骤都会在 **🕒 时间线** 标签页完整呈现（谁、什么时候、做了什么、从哪个状态变到哪个状态、备注是什么）。

## 🔍 六、触发异常场景验证

启动服务（`npm run dev` 或 `npm start`）后执行：

```bash
npm run trigger-error
```

脚本自动执行以下 6 个异常/边界场景并打印结果：

| # | 场景 | 预期结果 |
|---|---|---|
| 1 | 老人账号访问列表接口 | 返回字段数量 < 12，仅摘要视图 |
| 2 | 草稿直接归档（非法状态转换） | HTTP 400，状态机拒绝 |
| 3 | 批量提交（混合合法+非法+不存在 ID） | **部分成功**：合法成功部分成功，非法成功，失败项列出错误，时间线写入 `partial_success` 动作 |
| 4 | 主管状态回退（submitted → draft） | 状态回退成功，**审计日志保留完整记录回退前后状态、版本号、IP、原因** |
| 5 | 老人查看详情 | 仅摘要 + 精简时间线（无敏感字段） |
| 6 | 主管导出 CSV | 返回 CSV 文件下载 |

> **主管回退操作后，在记录详情页切换到"🔍 审计日志"标签即可查看回退留痕。

## 📤 七、导出操作

### 列表页导出（主管 / 父母可用）：

1. 用 `supervisor` 或 `parent` 登录 → 列表右上角 **"导出CSV"** 按钮 → 下载所有记录（当前状态筛选会一起生效）。

文件保存在 `backend/exports/` 下，文件名含时间戳。

### 单条记录时间线导出：

进入任意记录详情页 → 右上角 **"导出时间线"** 按钮 → 下载该条记录的完整时间线 CSV（主管可见审计也可）。

## 💡 常见问题

**Q: 怎么重置数据？
A: 删除 `backend/data/sleep-review.db`，再执行 `npm run seed`。

**Q: 批量提交部分成功后去哪看？
A: 主管登录进入首条成功的详情页，时间线标签会有紫色"部分成功"记录，审计标签会列出成功和失败 ID。

**Q: 回退后怎么查？
A: 主管登录进入记录详情 → "🔍 审计日志" 标签，包含前后状态、版本号、回退原因、操作 IP。
