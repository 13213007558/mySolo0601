## 1. 产品概述

茶叶杯测啜饮席——为茶叶拍卖行杯测师协会打造的专业杯测审评系统，解决啜饮时长无客观记录导致买家退赔的行业痛点。通过计时器与麦克风音量传感器联动，杜绝「凑时长」行为，保障杯测公正性与拍卖信用。

- 目标用户：茶叶拍卖行主评师、辅评师、审评室管理员
- 市场价值：消除人为计时漏洞，提升拍卖公信力，减少退赔纠纷

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 主评师 | 管理员分配账号 | 创建/管理批次、主导评分、锁定批次、签发证书 |
| 辅评师 | 管理员分配账号 | 参与评分、查看批次、辅助审评 |
| 管理员 | 系统预设 | 管理账号、查看审计日志、降级处理 |

### 2.2 功能模块

1. **登录页**：主评/辅评账号分离登录，角色权限区分
2. **批次仪表盘**：批次列表、状态总览、快速进入杯测
3. **杯测审评室**：核心交互页——勺量校验、啜饮计时、音量监测、四轴评分
4. **拍卖证书**：审评结束后自动生成证书草稿，主评师签发

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录页 | 角色登录 | 主评/辅评账号分离，登录后按角色跳转 |
| 批次仪表盘 | 批次列表 | 展示所有批次，状态筛选（待评/进行中/已锁定/已降级） |
| 批次仪表盘 | 新建批次 | 输入批次信息，关联标准样 |
| 杯测审评室 | 勺量校验 | 提示标准2.5g勺量，确认后才能开始啜饮 |
| 杯测审评室 | 啜饮计时器 | 开始啜饮即计时，实时显示已用时间 |
| 杯测审评室 | 音量监测 | 麦克风实时采集音量，低于阈值则标记异常 |
| 杯测审评室 | 作废判定 | 超时或音量不足→该样本作废→触发重评（最多2次） |
| 杯测审评室 | 四轴评分 | 外观/香气/滋味/叶底四轴打分，与标准样偏差带对比 |
| 杯测审评室 | 批次锁定 | 所有样本评完→锁定批次→禁止改序 |
| 拍卖证书 | 证书草稿 | 审评结束后自动生成，含批次信息、评分汇总、偏差分析 |
| 拍卖证书 | 主评签发 | 主评师确认签发，锁定证书 |

## 3. 核心流程

杯测师选择批次 → 确认勺量2.5g → 开始啜饮 → 计时器启动 + 音量采集 → 判定结果：
- 合格：进入四轴评分 → 偏差带对比 → 评分记录
- 不合格（超时/音量不足）：样本作废 → 重评（最多2次）→ 超过2次整批降级

所有样本评完 → 批次锁定 → 自动生成拍卖证书草稿 → 主评签发

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深琥珀金 (#C8956C) ——茶汤色泽，温暖专业
- 辅助色：暗炭黑 (#1A1614) ——审评室暗光环境基底
- 强调色：翠绿 (#4A7C59) ——茶叶本源色，用于合格/通过状态
- 警告色：铜锈红 (#A0522D) ——作废/降级警示
- 字体：Noto Serif SC（衬线，标题）+ Noto Sans SC（无衬线，正文）
- 布局：顶部导航 + 左侧批次面板 + 右侧主工作区
- 按钮：圆角微凸（2px），暖色系渐变，hover 发光效果
- 图标：线性风格（lucide），与暗光模式适配

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 登录页 | 角色登录 | 居中卡片，暗色背景，琥珀金Logo，角色选择下拉 |
| 批次仪表盘 | 批次列表 | 网格卡片，状态色标，hover 微动效 |
| 杯测审评室 | 勺量校验 | 居中确认弹窗，2.5g数字醒目，确认按钮 |
| 杯测审评室 | 啜饮计时器 | 圆形进度环，实时数字，琥珀金渐变 |
| 杯测审评室 | 音量监测 | 麦克风波形可视化，阈值线标红 |
| 杯测审评室 | 四轴评分 | 雷达图 + 滑块组，偏差带半透明叠层 |
| 杯测审评室 | 作废提示 | 红色横幅，重评/降级状态 |
| 拍卖证书 | 证书草稿 | 仿纸质证书排版，金色边框，水印底纹 |

### 4.3 响应式

桌面优先设计，适配审评室大屏（1920×1080为主）。移动端仅保留查看功能，核心杯测操作限定桌面端。

### 4.4 暗光模式

系统默认暗光模式，适配审评室低照度环境：
- 背景色：#1A1614（近黑暖棕）
- 卡片/面板：#2A2420（深棕）
- 文字：#E8DDD0（暖白）
- 边框：#3A3430（暗棕）
- 发光效果：关键操作元素使用微弱琥珀金辉光
