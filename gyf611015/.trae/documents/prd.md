## 1. 产品概述

珍珠蚌层测厚仪——面向育珠场的蚌层厚度数字化测量与分级管理工具。解决手工卡尺记录无照片佐证导致经销商扣款仲裁难题，实现多点测量录入、薄层追溯、自动分级拦截与复检留痕闭环。

- 核心用户：育珠场场长、测厚操作员、质检换班人员
- 核心价值：厚度数据可追溯、薄层区关联核珠批次、分级有据可依、复检合规留痕

## 2. 核心功能

### 2.1 用户角色

| 角色 | 操作权限 |
|------|----------|
| 操作员 | 录入测点厚度、查看直方图与历史曲线、发起分级 |
| 换班复检员 | 执行复检工单、确认异常测点、留痕签名 |
| 场长 | 查看全局数据、导出分级证书、配置分级阈值 |

### 2.2 功能模块

1. **蚌层厚度仪表盘**：多点测量录入、实时统计、薄层标红
2. **测量点示意图**：蚌壳SVG点击定位录入
3. **厚度分布直方图**：即时刷新的厚度频率分布
4. **薄层区追溯**：标红薄层区并关联核珠批次
5. **分级拦截与证书**：测点不足拦截、一键导出分级证书草稿
6. **历史厚度曲线**：对比同池历史厚度趋势
7. **复检工单系统**：异常自动触发、换班人员操作留痕

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 测厚仪表盘 | 厚度仪表区 | 实时显示当前蚌的所有测点厚度、平均值、最小值、标准差 |
| 测厚仪表盘 | 测量点示意图 | 蚌壳SVG轮廓，点击位置添加测点，已有测点可点击编辑 |
| 测厚仪表盘 | 薄层区标记 | 厚度低于阈值的测点红色高亮，显示关联核珠批次号 |
| 测厚仪表盘 | 厚度直方图 | 实时刷新的厚度分布直方图，含分级区间色带 |
| 测厚仪表盘 | 分级状态栏 | 测点数量达标检查、分级结果、证书导出按钮 |
| 测厚仪表盘 | 复检工单面板 | 异常测点自动触发的复检工单列表，含换班操作留痕 |
| 历史对比 | 厚度曲线叠加 | 当前蚌与同池历史样本厚度曲线叠加对比 |

## 3. 核心流程

## 5. 业务规则

### 5.1 分级拦截规则
- 单蚌测点少于 **8个** 时，不可进行分级
- 测点必须覆盖蚌壳至少 **3个象限**，否则不可分级

### 5.2 薄层判定规则
- 厚度 < 1.2mm 为薄层区，自动标红
- 薄层区必须关联核珠批次号

### 5.3 复检规则
- 单点厚度偏离均值 > 2倍标准差，自动触发复检
- 复检必须由不同班次人员操作
- 复检操作必须留痕（操作人、时间、结果）
