## 1. 产品概述

能源消防气瓶追踪面板是一款面向工业能源企业的消防气瓶全生命周期管理系统。系统解决消防气瓶状态追踪、巡检照片管理、审批流程追溯、手工补录差异对比等核心业务问题。目标用户包括现场巡检人员（小秦）、主管、数据分析人员。

### 核心价值
- 确保气瓶处理过程可追溯，刷新不丢失历史记录
- 照片缺失信息透明化，提供可读原因说明
- 审批流程可撤回，历史备注永久保留
- 补录数据可对比，导出读回一致性校验
- 数据ID一致性保障

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 巡检人员 | 现场巡检人员（小秦） | 录入巡检数据、补录气瓶信息、导出数据 |
| 主管 | 审批管理人员 | 审批结论、撤回重提、查看完整历史 |
| 管理员 | 系统管理员 | 配置管理、权限管理 |

### 2.2 功能模块

1. **消防气瓶追踪面板（首页）：气瓶列表、状态概览、处理历史、照片管理

2. **气瓶详情页**：气瓶信息、状态变更历史、审批记录、照片展示、异常原因说明

3. **补录管理页**：手工补录入口、补录前后差异对比、导出/读回验证

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：工业深蓝 (#0F172A) 背景，科技蓝 (#3B82F6) 主色，警示橙 (#F97316) 异常高亮
- **按钮风格**：直角边框、轻微阴影、悬停上浮效果
- **字体**：展示字体 - JetBrains Mono，正文字体 - Noto Sans SC
- **布局风格**：卡片式仪表盘布局，左侧导航，顶部状态栏
- **图标风格**：lucide-react 线性图标

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|---------|
| 追踪面板 | 状态概览卡片 | 统计卡片、状态徽章、数据网格、深色工业风背景 |
| 追踪面板 | 处理历史时间线 | 垂直时间线、状态节点、渐变色连接线 |
| 追踪面板 | 异常提示区 | 橙色警示卡片、可读原因标签、展开详情 |
| 追踪面板 | 补录样例区 | 高亮卡片、ID一致性标记 |
| 气瓶详情 | 信息卡片 | 信息网格、状态标签、操作按钮区 |
| 气瓶详情 | 历史记录列表 | 表格展示、备注区分显示 |
| 气瓶详情 | 照片展示区 | 照片网格、方向标注、异常标记 |
| 气瓶详情 | 审批操作区 | 撤回按钮、备注输入、历史备注展示 |
| 补录管理 | 补录表单 | 表单输入、压力贴纸预览 |
| 补录管理 | 差异对比区 | 左右对比布局、差异高亮 |
| 补录管理 | 导出读回区 | 导出按钮、读回验证、结果展示 |

### 4.3 响应式
桌面端优先设计，移动端自适应布局，触控优化。

### 4.4 动画与交互
- 页面加载时卡片依次淡入（staggered reveal）
- 状态变更时徽章颜色过渡动画
- 时间线节点悬停放大效果
- 异常卡片脉冲动画提示
- 滚动触发的渐入效果
