## 1. 产品概述

临电箱巡查台是一款面向建筑施工现场临电管理员的前端数据管理应用，用于配电箱巡查数据的导入、筛选、详情查看、异常处理与周报导出。通过可视化卡片式布局呈现漏保测试数据和风险分级，实现巡查数据的高效管理和闭环跟踪。

- 目标用户：建筑施工现场临电管理员、安全检查人员
- 核心价值：将纸质/分散的巡查数据数字化，自动风险分级，支持异常标记与整改闭环跟踪

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 临电管理员 | 数据导入导出、筛选查看、异常处理、派单管理、周报导出 |
| 安检人员 | 数据查看、筛选、详情查看、复查意见填写 |

### 2.2 功能模块

1. **数据总览页**：统计面板、数据列表、筛选控件、功能按钮区
2. **详情模态框**：现场照片、漏保测试值、派单详情、复查时间线
3. **异常处理面板**：异常标记、人工更正、重新验证

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据总览页 | 统计面板 | 显示总设备数、高风险数、已派单数、已复查数 |
| 数据总览页 | 筛选控件 | 区域多级联动、箱体类型多选、风险等级三选 |
| 数据总览页 | 数据列表 | 卡片式列表，支持排序分页，风险色彩化 |
| 数据总览页 | 功能按钮区 | 导入、导出JSON、导出CSV、筛选重置 |
| 详情模态框 | 现场照片 | 二维码照片展示，支持放大预览 |
| 详情模态框 | 漏保测试值 | 可视化展示正常/异常范围条形图 |
| 详情模态框 | 派单详情 | 派单状态跟踪（未派单→已派单→已整改→已复查） |
| 详情模态框 | 复查时间线 | 时间线展示复查意见记录 |
| 异常处理面板 | 异常标记 | 自动标记异常记录（二维码失败、漏保超界、重复箱体） |
| 异常处理面板 | 人工更正 | 允许修改异常字段并重新验证 |

## 3. 核心流程

用户导入JSON数据 → 系统自动解析验证与风险分级 → 管理员筛选查看数据 → 点击查看详情 → 发现异常进行标记/更正 → 创建整改派单 → 执行复查 → 导出周报

```mermaid
    "D" --> "E[查看详情]"

    "I" --> "J[整改执行"
    "J" --> "K[复查闭环"
    "K" --> "L[导出周报"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰 (#1e293b) + 电力橙 (#f97316) 作为强调色
- 辅助色：风险红 (#ef4444)、警告黄 (#eab308)、安全绿 (#22c55e)
- 按钮风格：圆角矩形，带微妙阴影，hover时提升
- 字体：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular
- 布局：卡片式布局，左侧筛选面板 + 右侧数据列表
- 图标：lucide-react 图标库

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 数据总览页 | 统计面板 | 四宫格统计卡片，数字大号展示，趋势箭头 |
| 数据总览页 | 筛选控件 | 级联选择器、多选标签组、三色风险按钮 |
| 数据总览页 | 数据列表 | 卡片网格，风险色左边条，漏保数据迷你图 |
| 详情模态框 | 照片区 | 照片缩略图网格，点击弹出大图 |
| 详情模态框 | 漏保测试 | 横向条形图，绿区/红区标注 |
| 详情模态框 | 派单区 | 步骤条展示状态流转 |
| 详情模态框 | 复查区 | 垂直时间线，节点圆点+连线 |

### 4.3 响应式

桌面优先设计，最小支持1280px宽度。平板端筛选面板折叠为顶部下拉，移动端卡片单列展示。
