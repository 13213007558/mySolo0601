# 风管综合排布协同页

这个项目是给暖通同事核对风管排布、标高调整、现场让路和协调纪要用的前端原型。页面数据来自静态样例和浏览器本地存储，不依赖后端接口。

## 启动

```sh
npm install
npm run dev
```

启动后打开终端输出的本地地址，例如 `http://localhost:5173/`。如果 5173 被占用，Vite 会自动换到下一个端口。

## 从空数据开始

第一次进入页面会看到空态提示。先观察平面区、问题列表和详情面板的空数据反馈，确认没有样例时页面不会误报楼层、标高或让路状态。

## 载入样例

点击页面右上角的 `载入样例`。系统会写入几条风管区域、标高变更、现场备注和协调问题到浏览器本地存储，刷新页面后这些样例仍会保留。

样例里包含三类反馈：

- 空态：未选择区域时，详情面板提示从平面图选择风管区域。
- 异常：空楼层、负标高、吊顶变更和现场让路问题会显示为待核对或冲突。
- 正常：已协调的区域会显示为绿色状态，并保留版本历史。

## 修改一条标高

1. 在平面定位区点击一个风管区域，例如 `A-1 主风管`。
2. 在右侧详情面板查看原标高、现标高、影响专业、关联问题和现场备注。
3. 点击 `调整标高`，输入新标高。可以输入毫米值，也可以切换到米制后输入米值；负标高和空楼层会给出提示。
4. 填写调整原因和操作人，点击 `确认调整`。
5. 到版本历史里检查本次调整是否出现；如果点击撤回，历史里会保留撤回前后的差异。

## 导出协调纪要

点击 `导出纪要` 后会打开预览弹窗。纪要包含标高变更、当前冲突、协调问题、现场备注和已解决问题。可以复制到剪贴板，也可以下载为文本文件。

## 本地数据

页面使用 IndexedDB 保存样例和操作记录。需要重新测试空态时，点击 `清空数据`，或在浏览器开发者工具里清理当前站点的 IndexedDB。

## 检查

```sh
npm run check
npm run build
```

`npm run check` 用来发现 Svelte 类型和可访问性问题；`npm run build` 用来验证生产构建。
