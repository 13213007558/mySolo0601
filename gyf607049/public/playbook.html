📘 操作手册 - 失败路径与人工更正路径

授权列表 审计中心 操作手册

❌ 失败路径：保健老师如何复盘

  1. 场景：电话授权 + 临时阿姨混合场景，操作人信息未正确记录
  2. 打开 审计中心，勾选 "仅显示处理人缺失"
  3. 找到 operator_display 为 "未知处理人" 或 "未注册" 的行
  4. 点击对应 授权ID 进入详情页
  5. 查看 审计日志 标签：对比 old_value → new_value，结合 detail 字段判断是谁改了什么
  6. 导出 Markdown / CSV，确认 页面摘要 与报告中的 状态、类型、照片说明、整改内容 完全一致

✅ 人工更正路径：主管复查后的修正步骤

  1. 场景：已关闭的记录需要追加材料，但部分材料格式错误或整改内容过长
  2. 进入详情页，点击 "追加材料" 上传照片或补充整改内容
  3. 系统返回 207 部分成功：查看 results 中 success / failed 分组
  4. 失败项：
    • 照片格式问题 → 转换为 jpg/png 后重新上传
    • 整改内容超过500字 → 精简后再次提交
  5. 成功项：照片下方可编辑 照片说明；整改记录可修改 处理人/状态/内容
  6. 完成后再次导出 Markdown，确认"追加-更正-导出"三阶段信息一致

🔄 服务重启后检查清单（护理主管）

重启服务后，重新打开任意详情页，逐项确认：

  • ✅ 页面摘要与列表一致（宝宝名、房号、类型标签、状态）
  • ✅ 每张照片的 说明文字 仍在
  • ✅ 状态 字段与关闭时一致（如"整改中"不应变回"待审核"）
  • ✅ 整改记录 的内容、处理人、状态均保留
  • ✅ 审计日志 不丢失，处理人缺失的行仍高亮显示便于复查
  • ✅ 导出 CSV/Markdown 与详情页肉眼一致
